# 📘 Curso SQL - Téo Me Why

Este repositório guarda os scripts e exercícios que eu fui fazendo durante o curso de SQL do canal Téo Me Why. A ideia é simples: servir como um caderno de anotações prático, onde cada arquivo corresponde a uma aula ou tópico específico. 📝

### 🎯 Sobre o Curso

O curso começa do zero e vai avançando aos poucos. No início, a gente aprende o básico do SELECT, depois vê como criar e manipular tabelas, passa por filtros com WHERE, ordenação com ORDER BY, expressões CASE, funções de contagem e soma (COUNT, SUM) e, por fim, estatísticas descritivas.

Cada assunto tem seu próprio arquivo numerado, então dá pra seguir na ordem e ir acompanhando a evolução. 🚀

### 🗃️ Dados de Exemplo

Pra facilitar a prática, o repositório traz um banco de dados de exemplo com dados fictícios de clientes, produtos e transações.

Esses dados estão em arquivos CSV e também em um arquivo SQLite pronto pra usar:
- 📄 clientes.csv
- 📄 produtos.csv
- 📄 transacoes.csv
- 📄 transacao_produto.csv
- 🗄️ database.db

Assim, dá pra rodar as consultas sem precisar montar nada do zero. 👌

### 📂 Organização

A estrutura é bem direta:
- 📜 Os scripts vão de 01_select.sql até 11_stats.sql, na mesma ordem das aulas.
- 🧪 A pasta exercicios/ tem práticas extras pra quem quiser treinar mais.
- 📊 Os arquivos CSV e o database.db são os dados que a gente usa nas consultas.

### 🚀 Como Usar

- Clone o repositório:
git clone https://github.com/sebrian-dev/Curso-SQL-Teo-Me-Why.git

- Abra os scripts no seu cliente SQL preferido (SQLite, DBeaver, etc.) 🖥️
- Execute na ordem numérica, do 01 ao 11. 🔢
- Depois de cada tópico, dá uma olhada na pasta exercicios/ pra fixar melhor. 💪
